# JISEO POP! — 〈왕벌의 비행〉 제품 컬렉션 게임

지나가던 사람이 **화면에 손만 대면** 시작되고, 림스키코르사코프 〈왕벌의 비행〉이
울리는 30초 동안 **위에서 쏟아지는 풍선을 손으로 쓸어 터뜨려 그 안의 제품을 모으는** 게임.

**점수가 아니라 "어떤 제품을 몇 종 모았는가"가 할인율과 증정품을 결정합니다.**

## 실행

```bash
open index.html          # 브라우저로 바로 열기
# 또는
python3 -m http.server 8000
```

> 소리는 브라우저 정책상 **첫 터치 이후** 재생됩니다. 우하단 🔊 버튼으로 음소거 가능.

## 💣 환불 폭탄 — 아래에서 두둥실 떠오른다

**위에서 떨어지는 풍선은 터뜨리고, 아래에서 떠오르는 폭탄은 피한다.**
이동 방향 자체가 규칙이라 설명 없이도 몇 초 만에 이해됩니다.

| | 풍선 | 💣 폭탄 |
|---|---|---|
| 방향 | 위 → 아래 | **아래 → 위** |
| 속도 | 553 px/s (1.8초 통과) | **444 px/s (2.2초 통과)** |
| 흔들림 | ±5~16px | **±14~26px** (크게 부유) |
| 실 | 위로 흩날림 | **아래로 늘어짐** |
| 생김새 | 제품 색 + 제품명 | 검은 풍선 + 붉은 점선 경고 링 + `위험` |

한 판(30초) 기준 실측: **떨어지는 풍선 60개(제품 44개) vs 💣 27개** — 평균 1.1초에 하나씩
올라오고, 동시에 최대 3개가 떠 있습니다. 제품:폭탄 = 1.6 : 1 이라 대충 쓸면 반드시 물립니다.
폭탄은 **풍선 표시 상한과 별도로 계산**되므로 폭탄을 늘려도 제품 노출량은 줄지 않습니다.

**만지면:**

1. **모은 제품 1개 회수** — 여유분(2개 이상)이 있는 제품부터 가져가므로 도감 *종류*는
   최대한 지켜집니다. 전부 1개씩뿐일 때만 가장 최근에 얻은 종류가 사라집니다.
2. 콤보 즉시 소멸 (쌓아둔 피버가 날아감)
3. 시간 −1.5초, 보너스 점수 −100
4. 화면 전체 붉은 섬광 + 강한 진동 + 저음 폭발음

**공정하게 만든 장치들**

- 시작 후 **3초 동안은 안 나옵니다** (규칙을 익힐 시간)
- 동시에 **최대 4개**까지만, 초반 4박 → 후반 2.5박 간격으로 점점 잦아집니다
- **피버 중에는 등장하지 않고**, 피버의 연쇄 폭발도 폭탄은 건드리지 않습니다
  (자동으로 벌점을 먹으면 억울하니까)
- 아무것도 못 모았을 때는 제품 회수 없이 시간·점수만 차감

너무 매우면 `CONFIG.bomb.everyBeatsStart/End` 를 `5 / 3` 으로 올리세요 (💣 27개 → 19개).

## 음악 — 〈왕벌의 비행〉 실제 연주 음원

`audio/bumblebee.mp3` — **미 공군 군악대(U.S. Air Force Band of the Rockies) 연주**.
미국 연방정부 공무상 저작물이라 **퍼블릭 도메인**입니다. 출처는 Wikimedia Commons,
상세 라이선스는 [`audio/CREDITS.md`](audio/CREDITS.md) 참고. (83.9초 / 128kbps / 1.45MB)

- 도입부 무음 1.45초를 건너뛰고 **1.42초 지점부터** 재생합니다.
- 템포는 온셋 자기상관 분석으로 측정: **♩ = 169.5 BPM**, 16분음표 **초당 11.3개**.
  풍선 낙하가 이 값에 맞춰져 있습니다.
- **음원이 없으면 자동으로 내장 합성 시퀀서로 폴백**합니다 (에셋 0바이트).
  톱니파 2개(-9센트 디튠) → 로우패스 → 급격한 감쇠로 벌 날갯짓 같은 스타카토를 내고,
  반음계 질주 모티프 100음표를 ♩=168로 연주합니다. 파일을 지우고 열어보면 확인됩니다.
- 음원을 바꾸려면 `AUDIO.bpm`을 **새 음원의 실제 템포로 반드시 맞추세요.**
  안 맞추면 풍선이 음악과 어긋납니다.

### 화면에 표시되는 곡 정보

대기 화면 하단과, 게임 시작 시 좌하단에 6초간 뜨는 "재생 중" 칩에 곡 정보가 나옵니다.
음원이 아니라 합성 폴백으로 재생될 때는 칩이 `실시간 합성 연주`로 바뀝니다.

> **왕벌의 비행 (Flight of the Bumblebee)**
> 니콜라이 림스키코르사코프 作, 1900년 · 오페라 〈술탄 황제의 이야기〉 3막
> 왕자가 호박벌로 변해 날아가는 장면을 묘사한 간주곡. 16분음표가 **초당 11개**로
> 쏟아지는, 가장 빠른 클래식 곡 중 하나입니다.

## 풍선이 곡의 속도에 맞춰 떨어진다

낙하 속도를 픽셀이 아니라 **박(beat) 단위**로 정의했기 때문에, 템포를 바꾸면 풍선도 같이 빨라집니다.

1박 = 0.354초, 30초 플레이 = 85박.

| | 낙하 시간 | 속도(800px 기준) | 투하 |
|---|---|---|---|
| 전반 15초 | 7.0박 = 2.48초 | 323 px/s | **2박에 1개** (1.4개/초) |
| 후반 15초 | 4.8박 = 1.70초 | 471 px/s | 매 박 1개 (2.8개/초) |
| 벌떼 러시 | 1.44초 | 555 px/s | 매 박 2개 + **곡 템포 ×1.18** |

박은 **음원의 실제 재생 위치(`audio.currentTime`)에서 뽑습니다.** 프레임이 튀어도 음악과
어긋나지 않고, 피버에서 `playbackRate`를 1.18로 올리면 곡과 풍선이 함께 빨라집니다.

음원이 0.4초 넘게 멈추면(버퍼링·스톨) **워치독이 타이머로 이어받아** 풍선 투하가 끊기지
않습니다. 합성 폴백 모드에서는 `AudioContext.currentTime`에 예약된 박 큐를 씁니다.

## 풍선 크기 · 밀도는 화면에 맞춰 자동 조절

반지름 = `min(화면폭, 화면높이×0.62) × 0.135` (44~78px로 제한),
동시 표시 개수 = 화면폭에 몇 개가 들어가는지로 계산 (4~10개).

| 기기 | 지름 | 화면폭 대비 | 동시 최대 | 제품명 글자 |
|---|---|---|---|---|
| 작은 폰 360×640 | 97px | 27% | **6개** | 15px |
| iPhone 14 390×844 | 105px | 27% | **6개** | 16px |
| iPad 세로 768×1024 | 156px | 20% | 8개 | 23px |
| 데스크톱 1440×900 | 151px | 10% | 10개 | 23px |
| 키오스크 세로 1080×1920 | 156px | 14% | 10개 | 23px |

- 제품명은 **흰 알약 배경 위에** 그려서 어떤 풍선 색에서도 또렷하게 읽힙니다.
- 화면을 세로 **레인**으로 나눠 최근에 쓴 레인을 피해 투하하므로 풍선이 겹쳐 보이지 않습니다.

## 제품 컬렉션이 핵심

- 전체 풍선의 **76%에 제품이 들어 있습니다** (일반 제품 66% + 골든 풍선 10%).
  30초 동안 약 64개가 떨어지고 그중 약 49개에 제품이 들었습니다.
- 풍선 표면에 **제품 이모지 + 제품명**이 그려져 있어 플레이 내내 제품이 노출됩니다.
- 풍선 색 = 제품 고유 색. 터질 때도 그 색으로 파티클이 흩어집니다.
- **골든 풍선(★)에는 레어/희귀 제품만** 들어 있습니다. + 시간 1.5초 보너스.
- 처음 획득하는 제품은 화면 중앙에 **제품 풀네임 + "NEW! 컬렉션 획득"** 연출 + 색종이 + 팡파레.

## 구매 전환 장치

1. **진입 장벽 0** — 버튼 없이 화면에 손이 닿는 순간 시작.
2. **100% 당첨** — 0종이어도 5% 쿠폰. 꽝이 없음.
3. **제품명 각인** — 대기 화면 라인업 → 풍선 표면 → 획득 연출 → 결과 그리드 → 증정 목록까지,
   한 판에 제품 이름을 최소 5번 보게 됩니다.
4. **못 모은 제품을 이름으로 호명** — "아깝다! ☀️ 데일리 선크림, 🎁 시크릿 기프트만 더 모았다면
   마스터 25% 였어요 😭" → 그 제품이 기억에 남고 재도전을 부릅니다.
5. **컬렉션 도감의 빈칸** — 회색으로 남은 칸이 곧 다음 목표.
6. **획득 제품 = 실물 증정품** — 결과 화면의 증정 목록을 받으러 매장 동선으로 들어옵니다.
7. **쿠폰 10분 만료 카운트다운** — 지나면 회색으로 죽습니다. 즉시 구매 유도.
8. **레어/희귀 등급** — 골든 풍선을 노리게 만드는 수집 욕구.
9. **이메일 입력 시 +5%** — 재방문 마케팅 DB (웹훅으로 즉시 수신).
10. **오늘의 컬렉션 랭킹 + 1위와의 종수 차이** — 경쟁심 재플레이.
11. **실시간 참여 티커** — 오늘 실제 참여 기록만 노출 (사회적 증거).
12. **자랑하기** — 수집한 이모지가 그대로 공유 문구에 들어갑니다.
13. **키오스크 자동 복귀** — 결과 화면 60초 방치 시 대기 화면으로.

## 우리 브랜드로 바꾸기

`game.js` 최상단 `CONFIG` 하나만 고치면 됩니다.

```js
products: [
  { id:'toner', emoji:'🌿', name:'수분 토너', short:'토너',
    rarity:'common',              // common | rare | legendary
    gift:'토너 30ml 트래블 사이즈', // 결과 화면 증정 목록에 그대로 표시
    c1:'#b6ffcf', c2:'#12c98a' }, // 풍선 색 (밝은색, 진한색)
  ...
],
tiers: [ { min:8, grade:'MASTER', label:'마스터', percent:25, perk:'...' }, ... ],  // min = 수집 종류 수
mix:   { product:0.62, golden:0.10, bomb:0.08 },  // 풍선 구성비
bomb:  { graceSec:3, riseBeats:6, maxOnScreen:4,
         everyBeatsStart:4, everyBeatsEnd:2.5,    // 등장 간격(박) — 클수록 쉬움
         timePenalty:1.5, scorePenalty:100 },     // 💣 난이도
fallBeatsStart: 7.0, fallBeatsEnd: 4.8, // 낙하 속도 (박 단위, 작을수록 빠름)
sizeRatio: 0.135, sizeMin: 44, sizeMax: 78,   // 풍선 크기
densityMin: 4, densityMax: 10                 // 동시에 떠 있는 개수
```

- 곡 템포: `AUDIO.bpm` (음원 사용 시) / `MUSIC.bpm` (합성 폴백). 낮추면 풍선도 함께 느려집니다.
- 풍선이 더 크거나 적었으면 하면 `sizeRatio`를 올리고 `densityMax`를 내리세요.
- 제품 수를 8개에서 바꾸면 HUD·결과 그리드·`tiers`의 `min` 값도 함께 조정하세요.
- 이모지 대신 실제 제품 사진을 쓰려면 `drawBalloon()`의 `fillText(b.product.emoji, …)`를
  미리 로드한 `Image`로 `drawImage` 하도록 바꾸면 됩니다.
- 색상: `style.css` 최상단 `:root` 변수.

## 📧 이메일 웹훅 — 기존 게임과 같은 Make.com 훅

`price-slasher-game` 이 쓰던 웹훅을 그대로 씁니다. 이미 연결되어 있으므로 **추가 설정 없이
바로 동작**합니다.

```js
const WEBHOOK = {
  url: 'https://hook.eu1.make.com/iv6p47wuoc7rqnh1fb8884y0n5l6buuf',
  provider: 'make',
  source: 'jiseo-pop-game',   // 기존 게임은 'price-slasher-game'
  clearKinds: 6               // 6종 이상 모으면 cleared=true
};
```

### 전송 방식 — JSON 이 아니라 form-urlencoded

Make.com 웹훅은 CORS preflight(OPTIONS)에 응답하지 않습니다. `Content-Type: application/json`
으로 보내면 preflight 가 발생해 **요청이 아예 막힙니다.**
그래서 `application/x-www-form-urlencoded` 로 보내 단순 요청(simple request)으로 만듭니다.
기존 게임이 쓰던 방식과 같습니다.

실패 시 `navigator.sendBeacon` 으로 한 번 더 시도하고, 이게 성공하면 재전송 큐에
넣지 않습니다 (**중복 발송 방지**). 둘 다 실패해야 큐에 쌓입니다.

### 보내는 필드

기존 시나리오가 이미 매핑해 둔 이름을 **그대로** 씁니다.

| 필드 | 예시 | 비고 |
|---|---|---|
| `date` / `time` | `2026-09-12` / `18:24:07` | KST |
| `email` | `hong@shop.co.kr` | |
| `code` | `JISEO-8P6G` | 기존 게임은 `WIN20-` / `MAIL20-` |

  하지 않습니다. 전송 상태는 아래에 작은 글씨로만 표시됩니다.
- 실패분은 기기에 쌓아뒀다가 **45초마다 / 온라인 복귀 시 자동 재전송**합니다
  (`jiseo_pop_outbox`). 설정 오류로 무한 반복되지 않도록 건당 5회까지만 시도합니다.
- **이름은 선택 입력**입니다. 부스에서는 입력 항목이 적을수록 전환율이 높습니다.
- **동의 체크박스가 필수**입니다 (목적·항목·보관기간 명시). 체크 없이는 제출되지 않습니다.

### 다른 서비스로 바꾸려면

`provider` 만 바꾸면 됩니다 — `web3forms`(+`accessKey`) / `formspree` / `formsubmit`.
이들은 CORS 헤더를 제대로 주므로 JSON 으로 전송합니다.

## 운영 시 주의

- `WEBHOOK.url` 을 비워두면 응모 정보가 **브라우저 localStorage에만** 남습니다
  (`jiseo_pop_leads`, `jiseo_pop_runs`, `jiseo_pop_outbox`). 기기를 초기화하면 사라집니다.
- 쿠폰 코드는 클라이언트 생성이라 위조 가능합니다. 혜택이 크면 서버 발급/검증으로 바꾸세요.
- 증정품 재고가 유한하다면 `tiers`의 `perk` 문구에 "소진 시 조기 종료" 고지를 넣으세요.

## 파일

```
index.html         화면 구조 (대기 / 카운트다운 / 결과)
style.css          비주얼·애니메이션·반응형
game.js            음원 재생·합성 폴백, 박자 동기 낙하, 터치 판정, 컬렉션·쿠폰 로직
audio/bumblebee.mp3  〈왕벌의 비행〉 미 공군 군악대 연주 (퍼블릭 도메인)
audio/CREDITS.md     음원 출처·라이선스·템포 측정값
```

`file://` 로 열어도 동작하지만, 일부 브라우저는 로컬 파일 음원 재생을 막습니다.
음악이 안 나오면 `python3 -m http.server` 로 띄워서 여세요.
